# Anatomy 3D

মেডিকেল স্টুডেন্টদের জন্য ইন্টার‍্যাক্টিভ 3D হাড়ের অ্যাটলাস। এখানে হাড় কম্পিউটারে আঁকা নয়, আসল মানুষের স্ক্যান থেকে নেওয়া। সাথে বইয়ের (BD Chaurasia, Snell, Gray's) সব অ্যানাটমিক্যাল পয়েন্ট, মাসল অ্যাটাচমেন্ট, রিলেশন, ভার্টিব্রাল লেভেল আর কুইজ, সব লেখা বাংলায়।

## এখন পর্যন্ত যে হাড়গুলো আছে

| হাড় | ফোল্ডার | অবস্থা |
|---|---|---|
| Sternum | `bones/sternum` | Datta অনুযায়ী মিলানো (পৃ. ১১, ১৪–১৬, ২০), শিক্ষকের রিভিউ বাকি |
| রিব: 1st, 2nd, typical (6th), 10th, 11th, 12th | `bones/ribs` | Datta অনুযায়ী লেখা (পৃ. ১৬–২০), শিক্ষকের রিভিউ বাকি |
| থোরাসিক কশেরুকা: typical (T6), T1, T9, T10, T11, T12 + "কোন নম্বর?" ট্রেনার | `bones/thoracic-vertebrae` | Datta অনুযায়ী লেখা (পৃ. ১২–১৪), শিক্ষকের রিভিউ বাকি |

## ফোল্ডারে কী আছে

```
viewer/            সব হাড়ের জন্য একই ভিউয়ার
  viewer.js        3D দৃশ্য, মোড, লেয়ার, পিন, কুইজ, ট্যাপ করে চেনা
  viewer.css       পেজের ডিজাইন
bones/<হাড়>/       প্রতিটা হাড়ের নিজের ফাইল
  index.html       পেজ: সেকশনের লেখা (ধরার নিয়ম, ফিচার, রিলেশন, ভাইভা ...)
  content.js       3D ভিউয়ারের লেখা ও সেটিং (ল্যান্ডমার্ক, মাসল, রিলেশনের বিবরণ)
  data/core.js     হাড়ের মেশ আর ল্যান্ডমার্ক (pipeline দিয়ে বানানো, হাতে বদলাবেন না)
  data/layers.js   মাসল, ভেসেল, অঙ্গ, কশেরুকা (pipeline দিয়ে বানানো)
                   (রিবে একই পেজে ছয়টা রিব: data/<রিব>-core.js, URL-এর #first, #second, #typical, #tenth, #eleventh, #twelfth দেখে লোড হয়)
pipeline/          স্ক্যান থেকে data/ বানানোর Python স্ক্রিপ্ট
  common.py        সব হাড়ের কমন টুল
  <হাড়>.py         ওই হাড়ের ল্যান্ডমার্ক, অ্যাটাচমেন্ট মাপার নিয়ম
  ids_<হাড়>.txt    কোন কোন স্ক্যান মেশ লাগবে
  fetch_meshes.sh  মেশ ডাউনলোড করার স্ক্রিপ্ট
tools/
  make_artifact.py একটা হাড়ের পেজ প্রকাশের জন্য dist/ ফোল্ডারে সাজায়
```

**ভিউয়ারের মোড:** অংশ, ল্যান্ডমার্ক, মাসল, রিলেশন, লেভেল, জয়েন্ট, "ডান না বাম?" (জোড়া হাড়ের side determination ট্রেনার), কুইজ। কোন হাড়ে কোন মোড থাকবে তা `content.js`-এর `modes` ঠিক করে।

**মূল নিয়ম:** যে জিনিস সব হাড়ে একই (যেমন বাটন, কুইজ, পিন, ল্যাগ কমানো), সেটা শুধু `viewer/`-এ বদলাতে হবে, তাহলে সব হাড়ে একসাথে বদলাবে। যে জিনিস একটা হাড়ের নিজের (লেখা, ল্যান্ডমার্ক), সেটা `bones/<হাড়>/`-এ থাকবে।

## নিজের কম্পিউটারে চালানো

```bash
cd bones/sternum
python -m http.server 8000
# ব্রাউজারে খুলুন: http://localhost:8000
```

`index.html` সরাসরি ডাবল-ক্লিক করে খুললে কাজ করবে না, কারণ ব্রাউজার file:// থেকে মডিউল লোড করতে দেয় না। তাই ছোট একটা সার্ভার চালাতে হয়।

## স্ক্যান থেকে ডেটা আবার বানানো

```bash
pip install -r pipeline/requirements.txt
bash pipeline/fetch_meshes.sh pipeline/ids_sternum.txt   # মেশ নামবে ../bp3d ফোল্ডারে
python pipeline/sternum.py                                # data/core.js ও layers.js বানাবে
```

মাপার পদ্ধতি:
- **Costal notch:** আসল costal cartilage স্টার্নামকে যেখানে ছোঁয়।
- **মাসল অ্যাটাচমেন্ট:** আসল মাসল হাড়ের ২.৫ মিমি-র মধ্যে যেখানে আসে।
- **ভার্টিব্রাল লেভেল:** ল্যান্ডমার্কের উচ্চতায় কোন কশেরুকা আছে।

যে স্ট্রাকচার স্ক্যানে নেই (যেমন internal thoracic artery, intercostal nerve, lymph node), সেগুলো আসল ল্যান্ডমার্ক মেপে বইয়ের বর্ণনা অনুযায়ী বসানো **স্কিম্যাটিক**, আর পেজে সেটা স্পষ্ট লেখা থাকে।

## নতুন হাড় যোগ করার ধাপ

1. `pipeline/ids_<হাড়>.txt`-এ দরকারি মেশের FMA নম্বর লিখুন। নম্বর পাবেন `parts_list_e.txt` থেকে।
2. `pipeline/sternum.py` কপি করে `pipeline/<হাড়>.py` বানান, আর ল্যান্ডমার্ক মাপার নিয়ম বদলান।
3. `bones/sternum/` কপি করে `bones/<হাড়>/` বানান, তারপর `content.js` আর `index.html`-এর লেখা বদলান। প্রতিটা হাড়ে একই সেকশন থাকবে: ধরার নিয়ম, ফিচার, আর্টিকুলেশন, অ্যাটাচমেন্ট, রিলেশন, ক্লিনিক্যাল, অসিফিকেশন, ভাইভা।
4. স্ক্রিপ্ট চালান, ব্রাউজারে খুলে দেখুন, তারপর অ্যানাটমির শিক্ষককে দিয়ে রিভিউ করান।
